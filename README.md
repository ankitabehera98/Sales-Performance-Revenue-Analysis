## 🎯 Business Objectives

- Monitor overall revenue generation and sales performance.
- Track monthly sales against assigned targets.
- Evaluate individual sales representative productivity.
- Analyze won, lost and open deal statuses.
- Calculate key sales performance indicators.
- Identify revenue trends and performance patterns.
- Present consolidated business insights through an Excel dashboard.

## 📊 Key Performance Indicators

| KPI                      | Purpose                                           | Business Application          |
| ------------------------ | ------------------------------------------------- | ----------------------------- |
| **Total Revenue**        | Measures revenue generated from sales.            | Revenue monitoring            |
| **Average Deal Value**   | Measures average value per deal.                  | Deal value evaluation         |
| **Target Achievement %** | Compares actual revenue against assigned targets. | Target performance monitoring |
| **Won Deals**            | Tracks successfully closed deals.                 | Sales effectiveness           |
| **Lost Deals**           | Tracks unsuccessful deals.                        | Deal outcome analysis         |
| **Open Deals**           | Monitors deals that are still in progress.        | Pipeline visibility           |

| **Monthly Revenue**      | Tracks revenue generated each month.              | Trend analysis                |
